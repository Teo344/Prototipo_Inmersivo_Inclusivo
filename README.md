# Prototipo de aplicación inmersiva inclusiva

Desarrollo de Software Aplicado al Dominio de la Interculturalidad · Octavo semestre
Estado: **Fase 4: Prototipo v0.1 funcional** (imágenes referenciales)

## Idea
**Sendero Cóndor Machay VR:** recorrido virtual inmersivo, en la web, por el sendero y la cascada **Cóndor Machay** (Rumipamba, cantón Rumiñahui, Pichincha), dirigido a **personas con discapacidad física** que no pueden recorrer un sendero de unos 8 km con pendientes, lodo y puentes. El sendero real además está cerrado desde agosto de 2025 por un derrumbe. Incluye contenido cultural kichwa (*kuntur machay* = refugio del cóndor).
